# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good intent, keep discussions about the work, and accept that maintainers make the final call on scope and direction.

Unacceptable behaviour includes harassment, personal attacks, publishing others' private information, and sustained disruption. Reports go to the maintainer, [@mirza-rizvi](https://github.com/mirza-rizvi), through a GitHub private message or by opening an issue asking for a private channel. Reports are handled confidentially. Consequences range from a warning to a permanent ban from the project's spaces.
