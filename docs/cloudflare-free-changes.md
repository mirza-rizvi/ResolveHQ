## Validation

- **63 Workers tests passed.** Existing and expanded tests cover signup, login, old password hashes, reset/change, CSRF, tenant authorization, retry/idempotency, bounded jobs and streamed attachments.
- **25 UI component tests and 3 desktop/mobile browser tests passed.** They cover the added recovery controls and existing inbox workflows.
- ESLint, TypeScript, production build, offline Cloudflare checks and Wrangler deploy dry-run passed. Final Worker upload: 1,279.17 KiB raw / 228.20 KiB gzip; 30 static assets.
- Fresh migrations and demo seed were applied only to a temporary local D1 database for browser checks; the existing local database was preserved.
- Synthetic benchmark results and their production-CPU limitations are recorded in [the audit](cloudflare-free.md). No Free production account or production CPU measurements were used.
